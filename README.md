## ✨ Features

- 🎮 **Interactive 3D Scene** — Immersive Three.js environment with physics simulation
- 🎬 **Smooth Animations** — Buttery-smooth transitions powered by GSAP
- 🖱️ **Custom Cursor** — Unique cursor experience tailored for desktop
- 🌊 **Cinematic Loading Screen** — Animated intro sequence before the main content
- 📱 **Fully Responsive** — Looks great on all screen sizes
- ⚡ **Blazing Fast** — Built with Vite for optimal performance
- 📊 **Vercel Analytics** — Real-time traffic insights integrated

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:
- **Node.js** `v18+`
- **npm** `v9+` or **yarn**

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/rish0000-dot/Portfolio.git

# 2. Navigate to the project directory
cd Portfolio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The app will be running at `http://localhost:5173` 🎉

### Build for Production

```bash
# Compile TypeScript & build the project
npm run build

# Preview the production build locally
npm run preview
```

## 🌐 Deployment

This portfolio is optimized for deployment on **Vercel**.

```bash
# Install Vercel CLI (if not already installed)
npm i -g vercel

# Deploy to Vercel
vercel --prod
```

Or simply connect your GitHub repo to [Vercel](https://vercel.com) for automatic deployments on every push! ✅
